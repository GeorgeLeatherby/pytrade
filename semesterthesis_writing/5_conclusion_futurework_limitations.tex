\section{Conclusion, Future Work, and Limitations}
\label{sec:conclusion}

\subsection{Conclusion}

The principal achievement of PyTrade is a trained hierarchical Portfolio Allocator Agent (PAA) that outperforms SPY buy-and-hold on mean validation return and on a held-out test block, under simulated trading frictions. Using Proximal Policy Optimization (PPO), hierarchical PAA run \texttt{00317}, configuration \texttt{10029}, achieves mean validation return \(\overline R_{\mathrm{val}}=20.01\%\), against SPY's \(11.58\%\). Cumulative test return \(R_{\mathrm{test}}=55.30\%\), the net gain relative to initial capital, exceeds SPY's \(22.22\%\). Test excess \(J_{\mathrm{test}}=33.08\) percentage points measures this return difference. SPY is the primary evaluation benchmark. The additional \(23.50\)-point test advantage over equal-weight buy-and-hold, which uses the same assets, supports value from the hierarchical PAA's allocation actions beyond access to the chosen universe (Table~\ref{tab:paa-validation-test}).

This outcome is obtained from open, high, low, and close prices and trading volume (OHLCV), together with Effective Federal Funds Rate (EFFR) information, without news, fundamentals, or order-book data. The shared market-feature vector \(\mathbf f_t^{\mathrm{mkt}}\) provides scale-adjusted inputs across eleven instruments while preserving historical context. Fractional-price feature \(\phi_t\) retains weighted price history, while daily cash return \(q_t\) connects account dynamics to changing interest rates. At differentiation order \(d^\ast=0.85\), normalized feature \(\phi_t\) uses 50 trading dates, within the 60-day purge. Its calibration excludes the final test. Their integration with account-dependent observations and cost-aware execution provides consistent interfaces for the Single-Asset Agent (SAA) and hierarchical PAA (Sections~\ref{sec:state} and~\ref{sec:simulator}). This reusable experimental framework is a substantial methodological and engineering contribution beyond the performance of any one trained policy.

The temporal-to-cross-sectional decomposition receives empirical support for the selected configuration. SAA run \texttt{00312}, configuration \texttt{01068}, achieves mean asset alpha \(\overline\alpha^{\mathrm{asset}}=3.33\) percentage points, defined as annualized SAA return minus same-asset buy-and-hold return. Isolated SAA accounts reproduce standalone validation cumulative returns within \(0.00002\) percentage points. The selected hierarchical PAA exceeds the cross-sectional-only PAA by \(0.42\) points in mean validation return and \(23.47\) points on test. Its test advantage over the AR(1) random-signal control PAA is \(28.67\) points. Sustained positive late-training validation excess \(D_{\mathrm{val}}^{\mathrm{SPY}}\), the mean terminal dollar advantage over SPY, further supports persistence beyond one isolated checkpoint (Figure~\ref{fig:excess_return_over_training}). These findings demonstrate a viable modular architecture and successful allocation using transferred SAA information (Section~\ref{sec:paa-results-discussion}).

The return gains do not imply universal risk-adjusted superiority. Maximum drawdown \(M\) measures the largest decline from a preceding account-value peak. Hierarchical PAA test drawdown \(M_{\mathrm{test}}=31.33\%\) exceeds SPY's \(9.13\%\), while the cross-sectional-only PAA combines test return \(R_{\mathrm{test}}=31.83\%\) with drawdown \(M_{\mathrm{test}}=9.51\%\). Sharpe ratio \(\mathrm{SR}\), annualized mean daily return relative to daily variability without cash-rate subtraction, also remains below SPY's for the selected PAAs. Stronger terminal return and greater interim risk are therefore distinct findings (Table~\ref{tab:paa-validation-test}).

\subsection{Limitations}
\label{sec:limitations}

The evaluation covers four repeatedly consulted validation regimes and one held-out test block. Selecting checkpoints and configurations across several seeds does not establish statistically significant architectural differences. The AR(1) random-signal control PAA has one noise realization per evaluation. The cross-sectional-only PAA has higher family-average validation excess \(\overline J_{\mathrm{val}}\), so the selected hierarchical PAA's advantage is not uniform across training runs. Fractional-differentiation calibration includes pre-test validation dates (Section~\ref{sec:state-ffd}). Validation and test horizons also differ.

The evaluated SAA and PAA configurations are long-only. They cannot borrow and sell an asset to profit directly from a price decline. Observations exclude the Volatility Index (VIX), which summarizes option-implied volatility, and order-book bids, offers, and liquidity. Daily closing-price replay therefore represents a restricted market view. Execution uses an idealized same-close assumption. The SAA and PAA observe the completed daily bar at date \(t\) and trade at that date's closing price \(P_t\), without data or order latency. Simplified Gold and Crude accounting omits contract multipliers, margin collateral, daily cash settlement, and rollover, the replacement of expiring futures. These mechanics matter for real futures trading.

Returns \(R\) include configured commission, spread, and market-impact charges, but exclude taxes and any fees or execution slippage outside the cost model (Section~\ref{sec:friction}). High turnover \(T\), cumulative traded notional relative to daily account value, makes cost sensitivity important. Daily cash return \(q_t\) is also an approximation. Retail investors cannot invest directly at EFFR \(f_t\), an annualized overnight federal-funds rate. Money-market funds offer related exposure, but fees and composition prevent exact replication of modeled cash return \(q_t\).

Finally, shadow-account consistency supports correct bookkeeping and agreement with standalone SAA evaluation, not predictive value by itself. Transfer combines action \(a_t^{(i)}\), exposure \(\rho_t^{(i)}\), Sortino \(S_t^{\mathrm{sh},(i)}\), and drawdown \(M_t^{\mathrm{sh},(i)}\), so the comparison does not isolate an action-only contribution. Shadow Sortino \(S_t^{\mathrm{sh},(i)}\) uses smoothed net return relative to downside variability, including cash carry and costs, with a \(0.005\) denominator floor and clipping to \([-3,3]\). It is not annualized. The cross-sectional-only PAA retains historical inputs and cash-account risk summaries. Neither their individual contributions nor attention alone are isolated.

\subsection{Future Work}
\label{sec:future-work}

A promising extension is a hierarchical PAA informed by several complementary SAA policies rather than one shared temporal policy. These could include a behaviorally informed SAA representing loss aversion or overconfidence, following the perspective reviewed in Section~\ref{sec:modular-composition} \cite{Charkestani.2026}. Loss aversion means weighting losses more strongly than equivalent gains. Overconfidence means assigning excessive certainty to one's estimates. A rule-based SAA could instead supply mean-reversion signals, which anticipate a return towards a reference level, from regression analysis fitted only on training periods. A behaviorally informed SAA might supply information more distinct from the hierarchical PAA's technical features. Whether that distinction improves performance remains an empirical question. Each SAA contribution should be tested through matched ablations, with isolated accounting and an explicit mechanism for discounting uncertain signals.

The current SAA shares network parameters \(\theta_{\mathrm{SAA}}\) across assets, rotating its assigned instrument between episodes and using a learned asset-identity embedding \(\mathrm{emb}(i)\), a trainable numeric representation of the instrument. Training a separate SAA per asset could capture instrument-specific behavior, although reduced data per model and greater training cost may increase overfitting. Separate ablations of action \(a_t^{(i)}\), holding fraction \(\rho_t^{(i)}\), and risk summaries \(S_t^{\mathrm{sh},(i)},M_t^{\mathrm{sh},(i)}\) would clarify which transferred quantities contribute useful information. Explicitly masking these risk-summary fields would also permit a completely shadow-information-free cross-sectional-only PAA comparison.

Stronger evaluation should combine additional untouched regimes, paired comparisons across more seeds, repeated randomized signals, and cost and tax sensitivity tests. Explicit futures accounting and an investable money-market cash proxy would improve deployment realism.

A further research direction is a monolithic PAA that jointly learns temporal representations and cross-asset allocation. Monolithic means using one jointly optimized policy instead of a separately trained SAA and hierarchical PAA. Comparing joint learning with the modular system on identical data and execution rules would examine when separate training or joint adaptation is more effective. A matched total training budget should include SAA pretraining for the hierarchical PAA. This provides a natural extension of the reusable framework rather than changing the objective of the present study.
